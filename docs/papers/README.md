# Papers

Copias en PDF de la literatura que usa la tesis.

## Reglas de esta carpeta

- **Los PDF no se versionan.** El `.gitignore` de esta carpeta los excluye: pesan
  y tienen derechos de autor. Lo que se versiona es este README y la lista.
- **Nombre del archivo**: `Apellido_Anio_PalabraClave.pdf`
  Ejemplos: `Osler_2003_currency_orders.pdf`, `MacKinnonWebb_2020_randomization.pdf`.
- **La lista completa**, con el aporte de cada paper y un resumen corto, vive en
  la pagina de Notion del grupo: "Papers de la tesis — Cuartinhos EUR/USD".
- Si un paper se cita en la propuesta o en el informe, su PDF deberia estar aca.

## Estado de verificacion

En la lista de Notion cada entrada trae una marca:

- Revista, volumen y hallazgo verificados.
- Referencia clasica sin verificar: confirmar el DOI antes de citarla.

## Nota para quien trabaje con el agente

Esta carpeta la crea y la mantiene el grupo a mano. El agente no necesita
escribir aca; solo puede leer los PDF si se le pide algo puntual sobre un paper.
